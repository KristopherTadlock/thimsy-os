# Linux research notes

Research for the Linux build: read-only findings, with sources, that feed decisions in [../DECISIONS.md](../DECISIONS.md). Each note cites its sources and marks guesses. Nothing in a note is decided until DECISIONS.md records it.

- [media-decode.md](media-decode.md): video and music decoding for the Linux alpha (OA-24): RK3566 hardware decode on mainline, FFmpeg's request-API status, the KMS/GBM hand-off, licensing, Buildroot, and the platform-layer mapping of Nano's Android media code.
- [portmaster.md](portmaster.md): PortMaster on Thimsy Linux (OA-22): how it runs ports, what Thimsy Base must provide, card and image layout, licences, risks and a staged plan.
