# nano/build/sources.txt: every file the builds outside Soong compile from nano/, listed once per
# section (docs/linux/IMPLEMENTATION.md C.1). Paths are relative to nano/. Read by
# nano/test/host/Makefile (awk), nano/cmake/sources.cmake (G6) and
# tools/nano-tree/tests/test_nano_sources.py, which checks it against nano/Android.bp with
# androidbp.py:
#   - every file in gammaos-nano's srcs is in exactly one of [core], [drm] and [firmware];
#   - [dropped-linux] is a subset of [firmware];
#   - [scrape] equals gammaos-nano-scrape's srcs;
#   - [test-unit]'s production files equal gammaos_nano_unit_tests' srcs, and its tests equal
#     test/unit/*_test.cpp without DsScreenLayout_test.cpp (drastic-nano's, a sibling's test);
#   - every listed file exists.
# Android.bp stays authoritative for Android; this file only partitions it. Fork-only: never in
# the patch (upstream.json's fork_only has build/**).
#
# [core], [drm], [firmware] and [dropped-linux] are GENERATED (G4): the path lines right below
# their headers come from the include census (tools/nano-tree/include_census.py: its SPLIT_DECISIONS
# and NOT_STUBBED tables hold the hand decisions). Do not edit those lines; change the tables, then
#   py -3.12 tools/nano-tree/include_census.py write   (also regenerates unit-closure.txt and
#                                                      tools/nano-tree/include-census.json)
# The other sections are edited by hand; run the same command afterwards.
