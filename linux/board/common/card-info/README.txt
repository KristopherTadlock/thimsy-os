Thimsy OS Linux @VERSION@ for the @MODEL@
=========================================

This memory card holds Thimsy OS, a Linux system for handheld game
consoles. This small drive only explains the card; Thimsy itself is in
partitions that Windows, macOS and Android do not show.

To use it:

1. Put the card in the @MODEL@ and switch it on.
2. The first start makes the games partition, a drive called THIMSY that
   fills the rest of the card. Put your games there, from the console or
   from a computer. This small drive is hidden from then on.

Do not format this card, and do not let Android "set up" this card or use
it as internal storage: either erases Thimsy. If a computer or a phone
offers to format the card, say no.

To start again, write the Thimsy image to the card again. A games
partition that is already on the card is kept.

Device id: @DEVICE@
